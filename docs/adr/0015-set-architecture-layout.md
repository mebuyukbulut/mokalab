# 0015 - Set Architecture Layout

# Durum 
Mokalab git gide daha büyük bir program haline gelmeye başladı. İlk başlarda birkaç sınıfla başlayan programımız artık onlarca sınıfın birleştiği bir yapıya dönüştü. Eklediğimiz bu ADR'ler bir nebze fayda sağlasa da yeterli olmuyor. 

# Karar
Geliştirme sürecini belli bir süre askıya alıp mimari yapıya odaklanılmalı. Bunun içinde software architecture konusuna çalışılmalı. 


# Alternatifler
Bu şekilde devam edebiliriz fakat artan karmaşıklık ilerde bir noktada patlayacaktır. Ayrıca düzenli bir yapıda geliştirme hızı da artacaktır. 


# Pozitif Çıktılar
- İyi mimari
- İyi dökümantasyon
- Ortalama geliştirme hızı artacaktır. 

# Negatif Çıktılar
- Daha fazla dökümantasyon işimiz olacak 
- Geliştirmeyi belli bir süre ciddi anlamda duraklatmamız gerekecek.
